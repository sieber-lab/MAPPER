# Analysis Exports

Manuscript-facing summary tables and analysis outputs exported from the notebooks.

These files are intended to make figure statistics and derived comparisons easier to inspect without rerunning the full notebook stack.

## Main contents

- `LLM_augmentation_experiment/` stores summary outputs for the text-augmentation comparisons used in Figure 3.
- `Feature_augmentation_experiment/` stores model and feature-set comparison outputs used in Figure 4.
- `figure4_novelty_modality_jumps/` stores exports for the structural novelty and modality-jump analyses.
- `uncertainty_estimator/` stores uncertainty benchmarking and calibration exports used in Figure 5 and Figure 6.
- `supplementary_stats/` stores compact manuscript-facing supplementary tables and validation summaries.
