# Notebooks

This folder contains the canonical notebook workflows used for data processing, figure generation, modeling, and supplementary analyses.

## Main subfolders

- `figure2/` to `figure6/` contain the primary manuscript figure workflows.
- `supplementary/` contains supplementary analyses and table-generation notebooks.
- `analysis/` contains reusable plotting and analysis helpers imported by the figure notebooks.
- `data_processing/` contains exploratory and preprocessing notebooks used during dataset assembly.
- `modeling/` contains model-development notebooks that are not directly tied to a single figure panel.
