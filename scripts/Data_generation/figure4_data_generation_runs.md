# Figure 4 Data Generation Runs

This file documents the exact commands to regenerate the data used in Figure 4a and Figure 4b from the curated `code_repository`.

Run from:

```bash
cd /mnt/jh/nas/PhD/Code/Ms_paint/code_repository
```

## Figure 4a (feature-combination screen across models)

### Prediction generation command

```bash
PYTHONPATH=scripts/Data_generation \
python3 scripts/Data_generation/Feature_eval_script.py \
  --exp_name Feature_augmentation_experiment \
  --task binary \
  --cv_splits 5 \
  --seed_splits 1 \
  --base_seed 42 \
  --cv_iterations 5 \
  --folds_manifest fold_manifests/figure4a_compound_folds.json
```

### What this run produces

- Raw prediction folders for each model/feature-combination run under:
  - `predictions/Feature_augmentation_experiment/binary/`
- Experiment-level metric summary:
  - `results/Feature_augmentation_experiment.pkl`

### Figure 4a analysis/export command

```bash
jupyter run notebooks/figure4/figure4_feature_replot.ipynb
```

### Figure 4a analysis outputs

- Root analysis folder:
  - `analysis_all_models_Feature_augmentation_experiment_binary/`
- Per model:
  - `<model>/<model>_per_cycle_all_metrics.csv`
  - `<model>/<metric>/<model>_per_cycle_<metric>.csv`
  - `<model>/<metric>/<model>_friedman_<metric>.csv`
  - `<model>/<metric>/<model>_pairwise_<metric>_pvals_BH.csv`
  - `<model>/<metric>/<model>_coalition_means_<metric>.csv`
  - `<model>/<metric>/<model>_winner_summary_<metric>.csv`
  - `<model>/<metric>/<model>_MCS_<metric>.csv`
  - `<model>/<metric>/<model>_pairwise_BH_<metric>.png`
- Global summary:
  - `analysis_all_models_Feature_augmentation_experiment_binary/summary_winners_all.csv`
