# Scripts

Reusable scripts for dataset generation, preprocessing, and uncertainty-estimation workflows.

## Main subfolders

- `Data_generation/` contains code used to assemble training-ready modality tables and related artifacts.
- `Preprocessing/` contains preprocessing utilities for compound metadata, growth curves, and proteomics inputs.
- `uncertainty/` contains the deployed uncertainty-estimation code and supporting utilities.

The figure notebooks in `../notebooks/` are the main entry points for manuscript reproduction; these scripts provide shared lower-level functionality.
