# Images

Exported figure assets used in the manuscript, Supplementary Information, and intermediate figure assembly.

## Main subfolders

- `main_figures/` contains the canonical exported main-figure PDFs used by the manuscript.
- `ext_figures/` contains extended-data figure PDFs.
- `supplementary/` contains supplementary figure assets.
- `figure2/` to `figure6/` contain notebook-level intermediate exports and panel-specific outputs.
- `data_processing/` contains supporting visualizations generated during preprocessing and QC.

When in doubt, the manuscript-facing assets are the PDFs under `main_figures/`, `ext_figures/`, and `supplementary/`.
