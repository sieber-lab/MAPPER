## Data objects and modality matrices
Base analysis matrices were loaded from serialized files under `Data/Base` (`X_proteomics.pkl`, `X_ecfp.pkl`, `X_cellpaint.pkl`, `X_mic.pkl`, `X_gc.pkl`, and `y_labels.pkl`). [ref: scripts/Data_generation/Feature_eval_script.py :: main data load :: `BASE_DIR = "Data/Base"`]
Text embeddings were loaded from semantic, sentence, and word augmentation files. [ref: scripts/Data_generation/train_primary_tabm.py :: parse args :: `--emb_sem`, `--emb_sentence`, `--emb_word`]
For Figure 2 exploratory panels, MIC values were extracted from MIC matrices using threshold-based extraction with `thresh=0.1`. [ref: notebooks/analysis/figure2_helpers.py :: `compute_mic_from_matrix` :: `thresh: float = 0.1`]
The structural chemistry embedding used UMAP with `n_neighbors=15`, `min_dist=0.1`, and `random_state=42`, with PCA fallback. [ref: notebooks/analysis/figure2_helpers.py :: `plot_ecfp_embedding` :: `umap.UMAP(n_neighbors=15, min_dist=0.1, random_state=42)`]
The proteomics embedding used standardization and UMAP with `n_neighbors=50`, `min_dist=0.5`, and `random_state=42`, with PCA fallback. [ref: notebooks/figure2/figure2_data_overview.ipynb :: `plot_proteomics_embedding` :: `StandardScaler`, `umap.UMAP(n_neighbors=50, min_dist=0.5, random_state=random_state)`]
Operator and batch quality control on the embedding used KMeans with `n_clusters=3` and `random_state=42`. [ref: notebooks/figure2/figure2_data_overview.ipynb :: code cell :: `KMeans(n_clusters=3, random_state=42)`]

## Pairwise formulation and feature assembly
Pairwise rows were built by crossing each sample with each candidate MoA embedding across augmentation indices. [ref: scripts/Data_generation/Codebase/eval_utils.py :: `generate_backbone_df` :: `for moa, embeddings in text_embeddings.items()`]
The pairwise label was assigned as `1` when candidate MoA matched true MoA and `0` otherwise. [ref: scripts/Data_generation/Codebase/eval_utils.py :: `generate_backbone_df` :: `"Label": int(moa == true_moa)`]
Feature vectors were assembled by concatenating selected modalities in declared order (`Text_Embedding`, `Proteomics`, `ECFP`, `CellPaint`, `MIC`, `GC`). [ref: scripts/Data_generation/Codebase/train_utils.py :: `build_features` :: `np.concatenate([r[m] for m in modalities])`; ref: scripts/Data_generation/Feature_eval_script.py :: modal dimensions block :: modality keys]
The no-text multiclass branch used sample-level modality matrices without text pair expansion. [ref: scripts/Data_generation/Feature_eval_script.py :: no-text branch :: `X_arr = build_features(sample_df, mods)`]

## Cross-validation, scaling, and randomness
Cross-validation folds were generated at compound level using stratified K-fold over one label per compound. [ref: scripts/Data_generation/Codebase/eval_utils.py :: `build_or_load_compound_folds` :: `StratifiedKFold(...)`]
Repeated CV used random state progression `base_seed + 1000*iter`, and within-fold seed replicas used `base_seed + rep_idx`. [ref: scripts/Data_generation/Codebase/eval_utils.py :: `build_or_load_compound_folds` and `evaluate_model` :: seed expressions]
Per-fold scaling in CV evaluators used `StandardScaler` fit on training rows followed by transform on held-out rows. [ref: scripts/Data_generation/Codebase/eval_utils.py :: `evaluate_model` :: `fit_transform` then `transform`]
TabM additionally applied `QuantileTransformer(output_distribution='normal')` internally on model inputs. [ref: scripts/Data_generation/Codebase/eval_utils.py :: `TabMWrapper.__init__` and `fit` :: `self.scaler = QuantileTransformer(...)`]
Seed initialization was explicitly set for Python, NumPy, and Torch in TabM and Lightning-style wrappers. [ref: scripts/Data_generation/Codebase/eval_utils.py :: `TabMWrapper._set_seed`; ref: scripts/Data_generation/Codebase/eval_utils.py :: `SklearnLikeLightningMLP.fit`]

## Metrics and statistical analyses
Binary evaluation included PR AUC, ROC AUC, and MCC in run/evaluation paths. [ref: scripts/Data_generation/Codebase/eval_utils.py :: `log_binary_metrics`; ref: notebooks/figure3/figure3_llm_parametric_tests.ipynb :: `safe_metrics_one_resample`]
The text versus no-text multiclass analysis computed macro F1, macro PR AUC (OvR), and macro ROC AUC (OvR). [ref: notebooks/figure3/figure3_text_augmentation_effects.ipynb :: metric block :: `macro_f1`, `macro_ap_ovr`, `macro_roc_ovr`]
Figure 3 repeated-measures analysis indexed each outer-fold pair as `cv_cycle = 5*cv_iter + fold_idx`. [ref: notebooks/figure3/figure3_llm_parametric_tests.ipynb :: test table construction :: `cv_cycle`]
Repeated-measures ANOVA and Tukey-style posthoc routines were provided through `rm_tukey_hsd`. [ref: notebooks/analysis/model_comparison.py :: `rm_tukey_hsd` :: `pg.rm_anova` and Tukey calculations]
Figure 4 significance testing used Friedman and Conover-Friedman procedures with BH correction. [ref: notebooks/figure4/figure4_feature_replot.ipynb :: analysis cells :: `pg.friedman`, `sp.posthoc_conover_friedman(..., p_adjust="fdr_bh")`]
Figure 5 pairwise uncertainty statistics included Holm-adjusted p-values and Cliff's delta with bootstrap confidence intervals (`N_BOOT = 5000`). [ref: notebooks/figure5/figure5_uncertainty_comparison.ipynb :: stats cells :: `holm_adjust`, `cliffs_delta_boot`, `N_BOOT = 5000`]

## Uncertainty modeling and calibration
The uncertainty comparison evaluated low max score, high predictive entropy, high expected entropy, Z-gate (global), Z-gate (class-conditional), and a meta-model (`LR+Poly`). [ref: notebooks/figure5/figure5_uncertainty_comparison.ipynb :: `run_eta_loo_per_compound` :: `methods = [...]`]
All uncertainty methods were calibrated to `TARGET_ID_FPR = 0.10` in the Figure 5 uncertainty notebook. [ref: notebooks/figure5/figure5_uncertainty_comparison.ipynb :: constants :: `TARGET_ID_FPR = 0.10`]
The exported meta-model pipeline used `StandardScaler` -> `PolynomialFeatures(degree=2)` -> `LogisticRegression(class_weight='balanced')`, wrapped by `CalibratedClassifierCV(method='sigmoid', cv=3)`. [ref: notebooks/figure5/figure5_uncertainty_comparison.ipynb :: deploy block :: `make_pipeline(...)`, `CalibratedClassifierCV(..., cv=3)`]
The shipped uncertainty artifact recorded `meta_threshold = 0.4690518117171519`, `target_id_fpr = 0.1`, and preprocessing directives including `negate=["PredScore","Margin"]` and `fillna_value=0.0`. [ref: models/uncertainty_estimator/meta_artifact.json :: keys]
Runtime uncertainty application used floor overrides before final `p_error` assignment, including forced `p_error=1.0` when floor criteria were triggered. [ref: scripts/uncertainty/uncertainty_estimator.py :: `_apply_meta_with_floor` :: `df.loc[df["floor_applied"], "p_error_meta"] = 1.0`]
